# Specification: SDLC Directory Restructuring

## Goal
To eliminate "root directory pollution" by consolidating all artifacts generated by the `atomic-sdlc` suite into a single, semantic container.

## Target Structure
All commands will now default to reading from and writing to the `./sdlc/` directory.

### Key Changes
1.  **Default Output Paths**: Every `.toml` command definition in `commands/atomic/` that specifies a default filename (e.g., `DISCOVERY_SPEC.md`) must be updated to include the `sdlc/` prefix (e.g., `sdlc/DISCOVERY_SPEC.md`).
2.  **Artifact Discovery Logic**: Prompts must be updated to prioritize searching the `sdlc/` directory when no explicit path is provided via `{{args}}`.
3.  **Naming Integrity**: The all-caps `PHASE_RESULT` naming convention (e.g., `DISCOVERY_SPEC.md`) is RETAINED to ensure tab clarity and searchability within the flat folder.

## Technical Constraints
- Every `.toml` file in `commands/atomic/` (including Orchestrators and Worker commands) must be updated.
- The `write_file` and `read_file` tool calls within prompts must reflect the new paths.
- The project documentation (`GEMINI.md`) must be updated to reflect the new directory structure.
